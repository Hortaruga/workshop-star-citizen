# Wiki-Citizen

Guia não oficial de Star Citizen em português: naves, modelos de equipamento, armas, componentes, salvage e onde vender.

Projeto de fã, sem vínculo com a Cloud Imperium Games ou a Roberts Space Industries. Star Citizen é marca de seus respectivos donos.

## Arquivos

- `index.html`: o site completo.
- `prices.json`: preços de venda de salvage, atualizados pela automação.
- `scripts/update_prices.py`: busca os preços na API do UEX e valida os dados antes de gravar.
- `.github/workflows/update-prices.yml`: roda a atualização todo dia às 07:17 (Brasília).

## Fontes

UEX, Star Citizen Wiki e scunpacked-data. A lista completa está na aba **Fontes** do site.
